# Zomato Sales Analysis

## About This Project

This is my Zomato Data Analysis project made using Excel.

I used a Zomato restaurant dataset and worked on it to understand different things about restaurants, ratings, costs, cuisines and locations. I used Excel formulas, Pivot Tables and charts to analyze the data.

## Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Data Analysis

## What I Did

In this project, I worked on the following things:

* Checked and organized the restaurant data
* Calculated different KPIs
* Found the total number of restaurants
* Calculated average ratings
* Calculated average cost for two people
* Calculated total votes
* Checked restaurants with online delivery
* Checked restaurants with table booking
* Compared restaurants by country
* Analyzed restaurants by city
* Checked popular cuisines
* Analyzed the rating distribution

## Excel Sheets

The Excel file contains different sheets:

### Dataset

This sheet contains the main Zomato restaurant data such as restaurant name, city, cuisines, cost, ratings, votes and other details.

### KPI's

This sheet contains important numbers calculated from the dataset, such as total restaurants, average rating, average cost, total votes and other KPIs.

### Pivot Charts

This sheet contains the analysis created using Pivot Tables and charts.

### Dashboard

A dashboard section is included in the Excel file to present the analysis in a simple visual format.

## What I Learned

By working on this project, I got practical experience in Excel data analysis. I learned how to work with a large dataset, use formulas, create KPIs, work with Pivot Tables and present data using charts.
